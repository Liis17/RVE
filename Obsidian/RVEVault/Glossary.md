# Glossary

Parent: [[Index]]

**Виртуальный путь** — имя ресурса в пространстве имён игры. Один и тот же путь используется для чтения ресурса из каталога Assets и из архива. [[Engine/EngineFiles]]

**RVEPAK** — формат архива ресурсов RVE. Каталог архива связывает виртуальные пути с записями, которые движок читает при загрузке. [[Engine/EnginePak]]

**Кеш сжатых блоков** — дисковый кеш rve-build в `<project>/.rve/pak-cache`: хранит сжатые chunks RVEPAK по ключу из хеша исходных байтов, параметров кодека и версии формата, чтобы повторная упаковка не сжимала неизменённые ресурсы. В коде: `BlockCache`. [[Engine/EnginePak]]

**Префаб** — шаблон объектов сцены, из которого создаются экземпляры. [[Engine/EngineScene]]

**Быстрый префаб** — префаб, который подготавливается при загрузке сцены и доступен для создания экземпляров во время игры. [[Engine/EngineRuntime]]

**Тяжёлый префаб** — префаб из каталога проекта, который можно загрузить по запросу во время игры. [[Engine/EngineProject]]

**Сохраняемый корень** — корневой объект, который вместе с поддеревом переносится в следующую сцену при смене сцены. [[Engine/EngineScene]]

**Маркер анимации** — именованная позиция в клипе, которая при пересечении активным движением отправляется скрипту отдельным callback. Избегать: notify, анимационное событие как синоним. [[Engine/EngineAnimation]]

**Отчёт о падении** — файл `crash-*`, который игрок или сервер пишет в каталог `Logs` после panic (`.txt` с хвостом лога и backtrace) или нативного падения (`.dmp`, minidump, пишет монитор падений). Избегать: краш-репорт, краш-дамп. [[Engine/EngineRuntime]]

**Монитор падений** — отдельный процесс `rve-crash-monitor`, который по запросу игры пишет minidump и завершается вместе с игрой. [[Engine/EngineRuntime]]

**Значимость** — фильтр трафика сервера: spawn-поддерево доходит до участника, только если оно в зоне значимости его наблюдателей или видно по другим правилам. Значимость не меняет права клиента. В коде: модуль `interest.rs`, `[network].interest_radius`, флаг `network_identity.always_relevant` (всегда значим). Избегать: relevancy, зона интереса как синоним. [[Engine/EngineNetwork]]

**Зона значимости** — сфера радиуса `[network].interest_radius` вокруг наблюдателя; вход при расстоянии до R, выход при расстоянии больше 1,1R. [[Engine/EngineNetwork]]

**Наблюдатель** — объект, принадлежащий участнику (владелец). От его позиции считается значимость spawn-корней для этого участника. [[Engine/EngineNetwork]]

**Номер появления (epoch)** — номер, который сервер назначает каждому появлению spawn-корня у участника. Сообщения прошлых появлений клиент отбрасывает. [[Engine/EngineNetwork]]

**Таблица строк** — TOML-файл одного языка в Assets: ключ строки → переведённая строка. Таблицы проекта перечислены в `[localization].tables`. В коде: `StringTable`, `Localization`. Избегать: словарь перевода, файл локали как синоним. [[Engine/EngineGui]]

**Ключ строки** — имя строки в таблицах строк, которое `.rveui` указывает вместо литерала (`text.key`, `placeholder_key`, `option_keys`). Строка берётся из текущего языка, затем из языка по умолчанию, иначе показывается сам ключ. [[Engine/EngineGui]]

**Версия схемы сохранений** — номер формата данных `rve.save`/`ctx.save()`, который задаёт игра в `[save] version`; файл сохранения хранит его в поле `version`, файл без поля имеет версию 0. Избегать: версия сохранения как синоним номера слота или версии игры. [[Engine/EngineScript]]

**Мигратор сохранений** — код игры, который по шагу переводит данные сохранения из версии N в N+1 до старта скриптов: Lua-файл `[save] migration` или экспорт `rve_save_migrate` библиотеки тяжёлых скриптов. [[Engine/EngineScript]]

**Остров** — компонента связности dynamic-тел по активным collision-парам; единица решения контактов и засыпания. Пары со static и kinematic телами принадлежат острову dynamic, но не соединяют острова. Избегать: кластер, группа контактов. [[Engine/EnginePhysics]]
