# Sandbox

Parent: [[Index]]

## Назначение

`sandbox` — оконное приложение и ручная проверка рабочего пути RVE: время, окно, рисование мешей с текстурой и светом через Vulkan, загрузка моделей FBX и текстур PNG из `assets`, аргументы запуска и изменение размера.

## Источники

| Файл | Значимый символ | Роль |
|---|---|---|
| `engine/sandbox/src/main.rs` | `parse_args`, `load_content`, `Sandbox`, `WindowHandler`, `main` | Разбор CLI, загрузка ресурсов, инициализация renderer, кадры и коды завершения |
| `engine/sandbox/src/content.rs` | `Content`, `Mesh` | Меши и текстуры кадра из демонстрационной сцены или модели; вписывание модели в единичный куб и замена текстур |
| `engine/sandbox/src/scene.rs` | `Scene`, `TRIANGLE_VERTICES`, `cube_mesh`, `checker_texture`, `triangle_view_projection`, `cube_view_projection`, `cube_model` | Геометрия и текстура демонстрационных сцен, матрицы камеры и модели через glam |
| `engine/sandbox/src/bootstrap.rs` | `load` | Чтение и проверка начального размера окна из рабочего каталога |
| `bootstrap.rves.example` | `WindowSizeX`, `WindowSizeY` | Шаблон локального файла настроек |
| `engine/sandbox/Cargo.toml` | зависимости `engine-core`, `engine-window`, `engine-render`, `engine-assets`, `glam` | Сборка приложения из рабочих крейтов и математика матриц |

## Публичные контракты

У бинарного крейта нет публичной Rust API. Командная строка:

| Аргумент | Поведение |
|---|---|
| `--frames N` | Выход после N вызовов презентации со статусом `Presented`; N — положительный `u64` |
| `--render-scale S` | Масштаб render resolution; конечное число в `(0, 1]` |
| `--resize-test` | Запускает сценарий изменения размера и сворачивания/восстановления |
| `--scene triangle\|cube` | Демонстрационная сцена; по умолчанию `cube` |
| `--model /путь.fbx` | Модель FBX из `assets` вместо сцены; нельзя сочетать с `--scene` |
| `--texture /путь.png` | PNG из `assets`, заменяющий текстуры всех мешей сцены или модели |

Повторные или неизвестные флаги, отсутствие значения, некорректное значение и сочетание `--scene` с `--model` дают код 2. Ошибка ресурса (`AssetError`) выводится как `Ошибка ресурса: …` и тоже даёт код 2 до создания окна. При сочетании `--resize-test` и `--frames` требуется N ≥ 120. Ошибка окна или renderer даёт код 1; успешное закрытие или завершение лимита — код 0.

Перед созданием окна `bootstrap::load` читает `bootstrap.rves` из текущего рабочего
каталога (обычно `build/`). `WindowSizeX` и `WindowSizeY` задают начальные ширину и
высоту клиентской области в физических пикселях. Формат — `Имя=Значение`, один
параметр на строку, значения — положительные `u32`. Пустые строки и пробелы вокруг
имени/значения допускаются, регистр имён учитывается. Если файла или параметра нет,
сохраняется соответствующее значение `WindowConfig::default()` (1280×720).
Ошибки чтения, неверный синтаксис, значения, неизвестные и повторные параметры
завершают запуск с кодом 2 до создания окна. Ошибки разбора содержат файл и номер строки.
Настройки читаются один раз при запуске. Шаблон хранится в репозитории, локальный
`build/bootstrap.rves` игнорируется Git и не перезаписывается приложением.

## Зависимости и взаимодействия

- Использует [[Engine/EngineCore]] для `Time`.
- Через [[Engine/EngineWindow]] реализует `WindowHandler`.
- Через [[Engine/EngineAssets]] с корнем `ASSETS_DIR` (`assets` в рабочем каталоге) загружает модель и заменяющую текстуру до запуска цикла окна.
- Через [[Engine/EngineRender]] создаёт Vulkan renderer, загружает текстуры содержимого через `create_texture` и меши через `create_mesh`, затем вызывает `render_frame` с `Frame`: матрица камеры, `DirectionalLight::default()` и по `DrawCommand` на меш с общей матрицей модели.

## Ограничения и важные детали

- По умолчанию создаётся окно `RVE Sandbox` размером 1280×720 и используется `render_scale = 1.0`.
- Сборка и запуск выполняются из `build/`; debug-бинарник находится в `build/debug/`. При инициализации sandbox сообщает фактический физический размер окна.
- Clear color и угол поворота меняются на основе `Time::elapsed()`.
- Треугольник вращается вокруг оси Z и масштабируется по более узкой стороне окна, чтобы сохранить пропорции; текстуры у него нет, он рисуется цветом вершин, нормаль +Z смотрит в камеру. Куб со стороной 1 состоит из 24 вершин: у каждой грани своя внешняя нормаль и развёртка UV на весь квадрат с верхом текстуры у верхнего края грани. Он покрыт процедурной шахматной текстурой 256×256 с клетками 32×32 и вращается вокруг осей Y и X. Модель FBX получает белый цвет вершин, вписывается в куб со стороной 1 с центром в начале координат (масштаб по наибольшей стороне bounding box, вырожденный bounding box только центрируется) и использует камеру и вращение куба. Камера стоит на расстоянии 3; перспектива `glam::camera::rh::proj::directx::perspective` (Y вверх, глубина `[0, 1]`, как требует renderer) с углом обзора 45° по более узкой стороне окна. Размер окна для пропорций берётся из `init` и `resized`.
- Resize test после 30 презентаций запрашивает физический размер 960×540; после 60 успешных презентаций сворачивает окно и восстанавливает его по wall-clock таймеру 250 мс, запрашивая 1280×720.
- Фактический размер из `request_inner_size` обрабатывается сразу, если winit его возвращает; иначе сценарий ждёт событие `Resized`. Сценарий проверяет фактические размеры и завершение восстановления.
- При свёрнутом окне sandbox не вызывает `render_frame`. Презентация засчитывается только для `FrameStatus::Presented`; `Skipped` не увеличивает счётчик `--frames`.
- `WindowHandler::exiting` удаляет renderer до освобождения окна. Ошибка сохраняется до возврата из `run`, чтобы после цикла определить код выхода.
