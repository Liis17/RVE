# Sandbox

Parent: [[Index]]

## Назначение

`sandbox` — оконное приложение и ручная проверка рабочего пути RVE: время, окно, Vulkan clear-and-blit, аргументы запуска и изменение размера.

## Источники

| Файл | Значимый символ | Роль |
|---|---|---|
| `engine/sandbox/src/main.rs` | `parse_args`, `Sandbox`, `WindowHandler`, `main` | Разбор CLI, инициализация renderer, кадры и коды завершения |
| `engine/sandbox/src/bootstrap.rs` | `load` | Чтение и проверка начального размера окна из рабочего каталога |
| `bootstrap.rves.example` | `WindowSizeX`, `WindowSizeY` | Шаблон локального файла настроек |
| `engine/sandbox/Cargo.toml` | зависимости `engine-core`, `engine-window`, `engine-render` | Сборка приложения из трёх рабочих крейтов |

## Публичные контракты

У бинарного крейта нет публичной Rust API. Командная строка:

| Аргумент | Поведение |
|---|---|
| `--frames N` | Выход после N вызовов презентации со статусом `Presented`; N — положительный `u64` |
| `--render-scale S` | Масштаб render resolution; конечное число в `(0, 1]` |
| `--resize-test` | Запускает сценарий изменения размера и сворачивания/восстановления |

Повторные или неизвестные флаги, отсутствие значения и некорректное значение дают код 2. При сочетании `--resize-test` и `--frames` требуется N ≥ 120. Ошибка окна или renderer даёт код 1; успешное закрытие или завершение лимита — код 0.

Перед созданием окна `bootstrap::load` читает `bootstrap.rves` из текущего рабочего
каталога (обычно `build/`). `WindowSizeX` и `WindowSizeY` задают начальные ширину и
высоту клиентской области в физических пикселях. Формат — `Имя=Значение`, один
параметр на строку, значения — положительные `u32`. Пустые строки и пробелы вокруг
имени/значения допускаются, регистр имён учитывается. Если файла или параметра нет,
сохраняется соответствующее значение `WindowConfig::default()` (1280×720).
Ошибки чтения, неверный синтаксис, значения, неизвестные и повторные параметры
завершают запуск с кодом 2 до создания окна. Ошибки разбора содержат файл и номер строки.
Настройки читаются один раз при запуске. Шаблон хранится в репозитории, локальный
`build/bootstrap.rves` игнорируется Git и не перезаписывается приложением.

## Зависимости и взаимодействия

- Использует [[Engine/EngineCore]] для `Time`.
- Через [[Engine/EngineWindow]] реализует `WindowHandler`.
- Через [[Engine/EngineRender]] создаёт Vulkan renderer и вызывает `render_frame`.

## Ограничения и важные детали

- По умолчанию создаётся окно `RVE Sandbox` размером 1280×720 и используется `render_scale = 1.0`.
- Сборка и запуск выполняются из `build/`; debug-бинарник находится в `build/debug/`. При инициализации sandbox сообщает фактический физический размер окна.
- Clear color меняется на основе `Time::elapsed()`.
- Resize test после 30 презентаций запрашивает физический размер 960×540; после 60 успешных презентаций сворачивает окно и восстанавливает его по wall-clock таймеру 250 мс, запрашивая 1280×720.
- Фактический размер из `request_inner_size` обрабатывается сразу, если winit его возвращает; иначе сценарий ждёт событие `Resized`. Сценарий проверяет фактические размеры и завершение восстановления.
- При свёрнутом окне sandbox не вызывает `render_frame`. Презентация засчитывается только для `FrameStatus::Presented`; `Skipped` не увеличивает счётчик `--frames`.
- `WindowHandler::exiting` удаляет renderer до освобождения окна. Ошибка сохраняется до возврата из `run`, чтобы после цикла определить код выхода.
